# 实验结果客观性说明（重要，先读这个）

> 这份文档说明本项目每个指标的**口径、边界与不可比之处**。
> 简历与 README 里出现的数字都能在这里找到它的适用条件。
> 如果你（或面试官）看到某个数字觉得"太好了"，请先来这里核对口径。

---

## 0. 一句话总结

**所有指标都是在 MovieLens-1M（6,040 用户 / 3,883 物品 / 100 万条评分）这个公开小数据集上跑出来的，
不能直接外推到亿级用户的工业场景。** 数字的意义在于"同一口径下 A 比 B 好多少"，
而不是"A 的绝对值有多高"。

---

## 1. 哪些数字看着漂亮，但需要打折看

### 1.1 DIN 的 CTR-AUC = 0.819

**口径**：valid 集，每位用户 1 个正例 + **99 条按 popularity^0.75 采样的负例**。

为什么要打折：

1. **这是"1 正 99 负"的排序口径，不是线上真实曝光口径**。真实场景里用户看到的候选是召回层筛过的，
   彼此更像，判别难度高得多。证据就在本项目里：同一个 baseline 模型换成**难负例口径**（召回 Top-200 里未点的样本），
   AUC 从 0.807 **直接掉到 0.517**（接近随机）。
   → 所以 0.819 这个数**只在易负例口径下成立**，绝不能说成"我的模型 AUC 0.82"。
2. 99 条负例的 AUC 天然比全库排序（3,883 条）好看，因为候选池小、干扰少。
3. MovieLens 是显式评分数据，"rating≥4 当点击"是代理口径，与真实点击流（含大量误点、位置偏差）不同。

**该怎么说**：「在 1 正 99 负的标准离线口径下，DIN 比 DeepFM 高 2.15pt AUC」——
**相对比较是可靠的，绝对值不要单独引用。**

### 1.2 冷启动 Recall@50 = 0.401 / 0.640

**口径**：93 件人工"抹除全部训练行为"的物品，3,975 个用户的 13,042 条 held-out 正向交互。

为什么要打折：

1. **这 93 件物品本来都是有真实行为数据的成熟物品**，我们只是人为把训练集里的记录删掉。
   它们的标题、类目、语义向量都是"正常物品"的质量。
   真实的新内容往往是低质、标题不规范、类目缺失的——那种情况下语义通道的效果会显著变差。
2. **候选池只有 93 件**，不是全库。从 93 件里挑 Top50 命中 0.40，与从 3,883 件里挑 Top50 命中 0.40 完全不是一个难度。
   → 这个数字**高估了真实冷启动的难度**。
3. "无通道时 Recall=0" 这个结论是**可靠的**（ID Embedding 未训练 → 向量随机，这是数学事实，不依赖数据集）。
   但 "0.401" 这个具体数值依赖候选池大小，换数据集会变。

**该怎么说**：「开了独立内容通道后，新内容从完全无法被召回（Recall=0）变为可被有效召回；
在 93 件候选的小池上 Recall@50 达 0.40」——**定性结论强，定量数值有池子大小的水分。**

### 1.3 Lookalike Lift = 3.88x / pLTV AUC = 0.918

**口径**：按时间轴后 20% 切未来窗口，5,363 个候选用户，种子 107 人。

为什么要打折：

1. **人群包只有 27~55 人**，样本太小，Lift 的置信区间很宽。真实场景要按 DAU 量级重做。
2. "高价值"的定义是**未来正向行为数 ≥ 全量 80% 分位**，而这个数据集里用户活跃度差异极大
   （有人 20 条行为、有人 2000 条），所以"高价值"很大程度就是"高活跃"。
   → **模型可能主要在预测活跃度，而不是预测真正的商业价值。** 从 permutation importance 也能看出：
   Top 特征是 `active_months`（活跃月数），这印证了上述担忧。
3. pLTV 的 AUC 0.918 里，有多少来自"预测活跃度的延续性"，我没有做进一步的拆解实验。

**该怎么说**：「两步法（相似度扩量 + 价值筛选）相比随机基线把高价值命中率从 20.8% 提到 77.8%」，
但**要主动承认标签口径偏向活跃度**。

### 1.4 类目打散让 NDCG@10 +9%

**口径**：DIN 精排 Top40 候选，重排取 Top10。

这个结果我一开始也觉得反直觉，核查后的解释是：

- 精排 Top10 里有大量**同系列/同类目**物品互相挤占（比如指环王三部曲占据 3 个坑），
  而留一法的 ground truth 只有 1 个物品，同质占位直接浪费了坑位；
- 打散后腾出的坑位给了不同类目的内容，命中概率反而上升。

**但这个结论依赖"ground truth 只有 1 个"这个留一法特性**。真实场景里用户未来会消费多个内容，
同质推荐的损失没有这么极端。→ **ILD +35% 是可靠的，NDCG +9% 是数据集特性放大的结果。**

### 1.5 质量分 AUC = 0.7276

**口径**：未来窗口 197,663 条真实交互，预测"这条曝光会不会被点击"。

这个数字**相对诚实**，因为它有对照组：热度 0.6186、未平滑原始 CTR 0.7394。
质量分比未平滑 CTR **略低**（0.7276 < 0.7394）——我没有把平滑说成"全面提升"，
它的真实价值在于**低曝光物品不再被噪声主导**（这是稳定性收益，不是精度收益）。

## 2. 哪些数字是可靠的（不依赖数据集特性）

| 结论 | 为什么可靠 |
| --- | --- |
| 多路融合 > 最强单路（0.257 vs 0.207） | RRF 的互补性增益是结构性的，不依赖具体数值 |
| 无冷启动通道时新内容 Recall = 0 | ID Embedding 未训练即随机向量，是数学事实 |
| baseline 在难负例口径下 AUC ≈ 0.517 | 直接暴露了"易负例指标虚高"，是本仓库最有价值的负面结果 |
| 4k 库上 Flat 比 IVF 好；20 万库上 IVF 快 5.7× | 延迟/召回的实测数据，与业务无关，纯工程结论 |
| CTR 的 A/B 差异不显著（p=0.66）且 MDE=6.56% | 我**没有**把它包装成"策略有效"，而是明确说是功效不足 |
| 两处数据泄漏的存在与修复效果 | 有回归测试守着，可复现 |

## 3. 我主动排除的"美化"操作

为了让数字可比，以下几件事我**没有做**：

1. **没有调参刷榜**：三个精排模型用同一套超参（id_dim=32, hidden=(256,128,64), lr=1e-3, 3~4 epoch），
   没有为 DIN 单独调参。如果调，DIN 还能再高。
2. **没有挑选 checkpoint**：全部按 valid 指标选 best，test 只用于最终报告，不参与任何决策。
3. **没有隐藏负面结果**：双塔打不过 ItemCF、难负例训练让易负例 AUC 从 0.807 掉到 0.695、
   质量降权让覆盖率掉 11.6pt、A/B 的 CTR 不显著——这些都写在 README 正文里。
4. **没有用 LLM 生成"看起来合理"的标签**：标签来自受控词表 + 向量相似度打分，可复现、可入库。
5. **ESMM 的负迁移没有掩盖**：它的 CTR-AUC（0.8142）低于纯 DIN（0.8190），README 里明确写了这是多任务的代价。

## 4. 如果要迁移到真实业务，最先会崩的三件事

1. **规模**：3,883 个物品 → 千万级物品。ItemCF 的 O(N²) 相似度矩阵直接爆掉，
   必须换成向量召回为主 + 倒排为辅；Faiss 要上 IVF-PQ + 分片。
2. **实时性**：本项目全是离线批处理。真实系统需要用户 Embedding 分钟级更新、
   新内容小时级入库、行为流实时特征。
3. **反馈回路**：模拟器（`14_online_sim.py`）的点击概率是从历史数据拟合的，
   **它无法模拟"新策略改变了用户行为，进而改变了训练数据"这个闭环**。
   真实系统里这是最难的部分（幸存者偏差、曝光偏差、位置偏差），本项目只做了曝光偏差的部分处理
   （popularity^0.75 负采样 + logQ 修正）。

## 5. 简历里该怎么写这些数字（建议口径）

**可以写**（相对比较、定性结论、有对照组的绝对值）：

- "多路召回融合较最强单路 Recall@50 提升 24%"
- "DIN 较 DeepFM CTR-AUC 提升 2.15pt（同输入对照）"
- "定位并修复行为序列标签泄漏，valid AUC 从 0.60 恢复到 0.82"
- "新内容冷启动 Recall@50 从 0 提升至 0.40（独立内容通道 + 扶持额度）"
- "难负例训练使真实曝光口径 AUC 从 0.52 提升至 0.74"
- "53 个 pytest 用例覆盖指标对拍与数据泄漏护栏"

**不建议单独写**（容易被追问口径而失分）：

- ❌ "模型 AUC 达 0.82"（不说口径就是虚报）
- ❌ "pLTV AUC 0.918"（标签偏向活跃度，且样本仅 5k 用户）
- ❌ "人群包 Lift 3.88x"（人群包只有 27 人）

**面试被追问时的标准回答**：
> "这个数是在 1 正 99 负的离线口径下测的。我同时测了难负例口径，同一个模型只有 0.517，
> 接近随机——所以我认为离线 AUC 的绝对值意义有限，我更看重同口径下的相对比较，
> 以及模型在真实曝光分布上的判别能力。"

这个回答本身就是一个加分项：它证明你**知道自己数字的边界**。
