## 1. 召回与索引

**定位**：ItemCF（IUF 加权、Top100 近邻）、双塔（batch softmax + logQ
流行度修正）、Faiss Flat/IVF/HNSW 三索引实测权衡。

**数字**：IVF 召回保持率 vs 吞吐的权衡曲线；库规模 4k→20 万的规模效应。

**追问**：
- 双塔为什么打不过 ItemCF（小物空间、Embedding 容量、训练时长）→ 主动承认并给调参路线
- HNSW/IVF 参数怎么选 → 建议用「召回保持率预算」反推 nlist/M/efSearch

## 2. 精排四模型同输入对照

**定位**：同一份特征 / 标签 / 切分，唯一变量是结构。

| 模型 | CTR AUC | 特点 |
| --- | ---: | --- |
| DeepFM | 0.7037 | FM 二阶交叉 + DNN 高阶 |
| DIN | 0.7295 | target attention 序列建模（+2.6pt） |
| ESMM | 0.7194 | 多任务串联共享（CTCVR 0.7877） |
| MMoE | 0.7714 | 并行专家 × 双门（CTCVR **0.8271**） |

**追问**：
- 为什么 DIN > DeepFM → 行为序列注意力捕获兴趣多样性；attention 打分单元是 [q,k,q-k,q*k]
- MMoE vs ESMM → 串联共享有跷跷板，任务门学分化（JS 散度 0.084）；caveat：epoch 数不同，结构贡献需同预算实验
- ESMM 解决什么 → CVR 的选择偏差（标签只在点击空间有定义），全曝光空间 pCTCVR = pCTR×pCVR

## 3. pCTR 校准（差异化亮点，主动讲）

**定位**：「AUC 看序，计费看绝对值」。

**数字**：负采样训练的模型 PCOC=17（整体高估 17 倍），AUC 对此完全沉默；
手写 PAV 保序回归后 PCOC=1.00、ECE 0.161→0.00004、序不变。

**追问**：
- 为什么高估 → 训练 1:1 采样 vs 线上 1:99 的先验失真（还有 in-batch logQ 问题）
- 为什么用保序回归不 Platt → 非线性映射更贴；单调性保 AUC
- 上线放哪 → 打分后置、按分桶缓存查表；重训后重校准

## 4. 泄漏与评测纪律（必讲，体现工程素养）

两个真实踩坑沉淀成回归测试：热度统计的 split 泄漏、评测负样本过近导致的
线下虚高。另有全时间轴先序评测：

**数字**：离线随机切分 AUC 0.704 vs 真实时间轴先序 0.686——
**时间泄漏水分 ≈ 2pt**，量化了「离线自测的乐观偏差」。

## 5. A/B 框架

**定位**：SRM 校验 / 用户级 bootstrap / CUPED / MDE 功效分析。

**数字**：CUPED 方差削减 26.2%；冷启+质量策略 CTR 差 −0.002（p=0.66 不
显著）但 MDE=6.56% → 结论是「功效不足」不是「策略无效」。

**追问**：MDE 怎么算、为什么 CTR 没涨还敢说值得推 → CVR +8.9%、新内容
曝光 0→1.12%，OEC 决定结论。

## 6. 生产化 serving 八模块

**定位**：特征快照+TTL、护栏（频控/曝光/质量+**过严自动降级**）、候选缓存
LRU+TTL、哈希分层实验、p50/p95/p99+PSI 漂移+Prometheus 格式、
曝光-点击事件流（位置偏差/SNIPS 去偏）、注册表（staging 护栏/原子切换/
一键回滚）。

**数字**：600 请求演练 p95 20ms；护栏降级在同用户高频刷新下自动触发保供给。

## 7. 真实流量三件套

**定位**：98.8 万条真实评分按时间戳回放 + 在线增量学习 + 真实并发压测。

**数字**：先序 AUC 0.686（热度基线 0.610）；首窗 0.795 时间局部性 →
在线更新稳住 0.69；top-100 每窗换手 17.5%；压测 QPS 40.8 / p95 340ms。

**追问**：
- 为什么不做真 Kafka/Flink → 单机教学实现，语义等价；主动说出分布式形态
- 回放与真实 A/B 差在哪 → 策略不影响用户行为，反馈回路未闭合

## 8. 诚实边界（主动讲）

难负例未回流主链路（0.517→0.742 是独立口径）；MMoE 对照有 epoch 差；
点击是合成的；KNN 人群包仅 55 人规模。**知道自己项目边界 = 最强加分项。**
